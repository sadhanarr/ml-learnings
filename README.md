# ML & Deep Learning Core

Repository dedicated to practical implementations, course modules, and lab assignments completed as part of the **IIT Bombay Post Graduate Program in AI & Data Science**.

---

## 📌 Focus & Objectives
* **Foundational Machine Learning:** Implementation of core supervised and unsupervised algorithms from scratch and using standard libraries (`scikit-learn`, `numpy`, `pandas`).
* **Deep Learning Architectures:** Building, training, and fine-tuning neural networks using modern frameworks (`PyTorch` / `TensorFlow`).
* **Coursework & Labs:** Applied projects, hands-on exercises, and code implementations aligned with the IIT Bombay PGD curriculum.
